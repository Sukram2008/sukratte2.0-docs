# 🗑️❌ | Item löschen

Befehl: **`/shop delete`**

### Optionen
- **`item-name:`**
  Der Name des zu löschenden Items.
- **`item-id:`**
  Die ID des zu löschenden Items.

:::info Tipp: Sicherer Weg
Nutze am besten die **`item-id`**, um sicherzustellen, dass das korrekte Item dauerhaft entfernt wird.
:::

### Beschreibung
Entfernt ein Item unwiderruflich aus dem Shop-Sortiment. Bereits gekaufte Rollen bleiben bei den Nutzern bestehen.

### Berechtigungen

:::warning Zusätzliche Berechtigungen
Die Unterbefehle `/shop add`, `/shop edit` und `/shop delete` können nur von Administratoren ausgeführt werden. Da aktuell keine Administrator-Rollen konfiguriert sind, haben nur Bot-Operatoren Zugriff auf diese Funktionen.
:::
