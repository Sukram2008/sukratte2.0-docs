# ➕🛒 | Item hinzufügen

Befehl: **`/shop add`**

### Erforderliche Optionen

- **`item-name:`**
  Der Name des Items, wie er im Shop angezeigt wird.
- **`item-id:`**
  Eine eindeutige ID für das Item (wichtig für Kauf und Bearbeitung).
- **`price:`**
  Der Preis in der Server-Währung.
- **`role:`**
  Die Rolle, die der Nutzer beim Kauf erhalten soll.

### Beschreibung

Mit diesem Befehl fügst du dem Server-Shop ein neues Produkt hinzu. Nutzer können dieses Item anschließend gegen ihr erspartes Guthaben erwerben.

### Berechtigungen

:::warning Zusätzliche Berechtigungen
Die Unterbefehle `/shop add`, `/shop edit` und `/shop delete` können nur von Administratoren ausgeführt werden. Da aktuell keine Administrator-Rollen konfiguriert sind, haben nur Bot-Operatoren Zugriff auf diese Funktionen.
:::
