# 🧨⚠️ | Wirtschaft zurücksetzen

Befehl: **`/economy destroy`**

### Andere Optionen

- **`confirm:`** [Optional]
  Bestätigung der Löschung (`True` / `False`).
  > **Hinweis:** Nur bei Auswahl von `True` wird die Datenbank gelöscht. Bei `False` passiert nichts.

### Beschreibung

Dieser Befehl löscht die komplette Wirtschafts-Datenbank des Servers und setzt alle Fortschritte unwiderruflich zurück.

:::danger Absolute Warnung
Dieser Vorgang **zerstört alle Daten** sämtlicher Nutzer. Alle Kontostände werden gelöscht und auf Null gesetzt. Dies kann nicht rückgängig gemacht werden!
:::

### Berechtigungen

:::warning Zusätzliche Berechtigungen
Einige Befehle dieses Moduls können nur von den in der Konfiguration festgelegten Administratoren ausgeführt werden. Dies betrifft insbesondere Befehle, die den Kontostand von Nutzern verändern oder das Wirtschaftssystem verwalten.
:::
