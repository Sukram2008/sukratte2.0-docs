# 🔇 | Nutzer stummschalten

### 📦 Zugehöriges System

**Moderation & Sicherheit**

### 🖱️ Kontextmenü-Aktion

**`Mute`**

### Beschreibung

Mit dieser Nutzer-Aktion kann ein Nutzer direkt über das Discord-Kontextmenü stummgeschaltet werden.

Die Aktion ermöglicht es berechtigten Teammitgliedern, die Mute-Funktion direkt über den Nutzer aufzurufen, ohne dafür einen separaten Moderationsbefehl verwenden zu müssen.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `Mute`**
