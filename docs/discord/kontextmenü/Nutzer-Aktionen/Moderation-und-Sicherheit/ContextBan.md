# 🔨 | Nutzer bannen

### 📦 Zugehöriges System

**Moderation & Sicherheit**

### 🖱️ Kontextmenü-Aktion

**`Ban`**

### Beschreibung

Mit dieser Nutzer-Aktion kann ein Nutzer direkt über das Discord-Kontextmenü vom Server gebannt werden.

Die Aktion ermöglicht es berechtigten Teammitgliedern, einen Nutzer direkt über dessen Kontextmenü zu bannen, ohne dafür zunächst einen separaten Moderationsbefehl ausführen zu müssen.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `Ban`**
