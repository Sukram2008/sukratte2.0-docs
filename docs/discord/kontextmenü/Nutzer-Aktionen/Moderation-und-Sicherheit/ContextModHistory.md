# 👢 | Nutzer kicken

### 📦 Zugehöriges System

**Moderation & Sicherheit**

### 🖱️ Kontextmenü-Aktion

**`Kick`**

### Beschreibung

Mit dieser Nutzer-Aktion kann ein Nutzer direkt über das Discord-Kontextmenü vom Server gekickt werden.

Der Nutzer wird dabei aus dem Server entfernt, kann dem Server jedoch grundsätzlich erneut beitreten, sofern keine zusätzliche Sperre besteht.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `Kick`**
