# 📜 | Moderationshistorie anzeigen

### 📦 Zugehöriges System

**Moderation & Sicherheit**

### 🖱️ Kontextmenü-Aktion

**`Mod History`**

### Beschreibung

Mit dieser Nutzer-Aktion kann die Moderationshistorie eines Nutzers direkt über dessen Discord-Kontextmenü aufgerufen werden.

Dabei können die für den Nutzer gespeicherten Moderationsinformationen eingesehen werden. Die Aktion ermöglicht es dem zuständigen Team, die bisherige Moderationshistorie eines Nutzers schnell zu prüfen.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `Mod History`**
