# 🚫 | Nutzer blockieren

### 📦 Zugehöriges System

**Anonymer Chat**

### 🖱️ Kontextmenü-Aktion

**`Block User`**

### Beschreibung

Mit dieser Nutzer-Aktion kann ein Nutzer direkt über das Discord-Kontextmenü für den anonymen Chat blockiert werden.

Die Aktion ermöglicht es berechtigten Teammitgliedern, einen Nutzer direkt aus dem Kontextmenü heraus zu blockieren. Dadurch können Nutzer, die beispielsweise gegen die Regeln des anonymen Chats verstoßen, direkt über die entsprechende Nutzer-Aktion bearbeitet werden.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `Block User`**
