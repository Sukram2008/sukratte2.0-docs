# 🔥 | Aktivitätsserie anzeigen

### 📦 Zugehöriges System

**Aktivitäts-Streaks**

### 🖱️ Kontextmenü-Aktion

**`View Streak`**

### Beschreibung

Mit dieser Nutzer-Aktion kann die aktuelle Aktivitätsserie eines Nutzers direkt über dessen Discord-Kontextmenü angezeigt werden.

Die Aktion ermöglicht es, die Streak-Informationen eines Nutzers schnell aufzurufen, ohne dafür einen separaten Befehl ausführen zu müssen.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `View Streak`**
