# 🎂 | Geburtstag anzeigen

### 📦 Zugehöriges System

**Geburtstags-Kalender**

### 🖱️ Kontextmenü-Aktion

**`View Birthday`**

### Beschreibung

Mit dieser Nutzer-Aktion kann der im Geburtstags-Kalender hinterlegte Geburtstag eines Nutzers direkt über dessen Discord-Kontextmenü angezeigt werden.

Dadurch lässt sich die Geburtstagsinformation eines Nutzers schnell aufrufen, ohne zuerst einen separaten Befehl verwenden zu müssen.

### Verwendung

Öffne das Kontextmenü des gewünschten Nutzers und wähle:

**Apps → `View Birthday`**
