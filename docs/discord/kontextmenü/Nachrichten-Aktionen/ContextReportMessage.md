# 💬 | Nachricht zitieren

### 📦 Zugehöriges System

**Message Quotes**

### 🖱️ Kontextmenü-Aktion

**`Quote Message`**

### Beschreibung

Mit dieser Nachrichten-Aktion kann eine vorhandene Nachricht direkt über das Discord-Kontextmenü zitiert werden.

Die ausgewählte Nachricht wird dabei als Grundlage für das Zitat verwendet. Dadurch können Nachrichten schnell aufgegriffen und im dafür vorgesehenen System weiterverwendet werden, ohne den Inhalt manuell kopieren zu müssen.

### Verwendung

Öffne das Kontextmenü der gewünschten Nachricht und wähle:

**Apps → `Quote Message`**
