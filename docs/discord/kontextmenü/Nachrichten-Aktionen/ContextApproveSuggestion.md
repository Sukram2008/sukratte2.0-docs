# ✅💡 | Vorschlag akzeptieren

### 📦 Zugehöriges System

**Vorschläge**

### 🖱️ Kontextmenü-Aktion

**`Approve Suggestion`**

### Beschreibung

Mit dieser Nachrichten-Aktion kann ein vorhandener Vorschlag direkt über das Kontextmenü einer Nachricht akzeptiert werden.

Die Aktion wird bei einer Nachricht verwendet, die zu einem Vorschlag gehört. Nach der Ausführung wird der Vorschlag entsprechend als **angenommen** verarbeitet.

Dadurch muss die zuständige Person nicht erst einen separaten Befehl ausführen oder die Vorschlags-ID manuell eingeben.

### Verwendung

Öffne das Kontextmenü einer Vorschlagsnachricht und wähle:

**Apps → `Approve Suggestion`**
