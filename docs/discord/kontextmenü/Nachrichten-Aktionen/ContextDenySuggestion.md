# ⏰ | Erinnerung erstellen

### 📦 Zugehöriges System

**Erinnerungen**

### 🖱️ Kontextmenü-Aktion

**`Create Reminder`**

### Beschreibung

Mit dieser Nachrichten-Aktion kann direkt über das Kontextmenü einer Nachricht eine Erinnerung erstellt werden.

Dadurch kann eine Nachricht als Bezugspunkt für eine spätere Erinnerung verwendet werden. Die Aktion ist besonders praktisch, wenn du eine Nachricht später erneut beachten oder dich an deren Inhalt erinnern lassen möchtest.

### Verwendung

Öffne das Kontextmenü der gewünschten Nachricht und wähle:

**Apps → `Create Reminder`**
