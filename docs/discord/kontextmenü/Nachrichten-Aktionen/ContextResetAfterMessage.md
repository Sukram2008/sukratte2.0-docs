# 🚩 | Nachricht melden

### 📦 Zugehöriges System

**Moderation & Sicherheit**

### 🖱️ Kontextmenü-Aktion

**`Report Message`**

### Beschreibung

Mit dieser Nachrichten-Aktion kann eine Nachricht direkt über das Discord-Kontextmenü gemeldet werden.

Die ausgewählte Nachricht wird dabei als Grundlage für die Meldung verwendet. Dadurch können problematische oder regelwidrige Nachrichten schnell an das zuständige Team weitergegeben werden.

### Verwendung

Öffne das Kontextmenü der entsprechenden Nachricht und wähle:

**Apps → `Report Message`**
