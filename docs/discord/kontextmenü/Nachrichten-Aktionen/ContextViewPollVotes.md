# 📊 | Umfrage-Stimmen anzeigen

### 📦 Zugehöriges System

**Umfragen**

### 🖱️ Kontextmenü-Aktion

**`View Poll Votes`**

### Beschreibung

Mit dieser Nachrichten-Aktion können die abgegebenen Stimmen einer Umfrage direkt über das Kontextmenü der entsprechenden Umfragenachricht eingesehen werden.

Die Aktion ermöglicht es, die zugehörigen Abstimmungsinformationen direkt über die Nachricht aufzurufen, ohne dafür zuerst einen separaten Befehl ausführen zu müssen.

### Verwendung

Öffne das Kontextmenü der entsprechenden Umfragenachricht und wähle:

**Apps → `View Poll Votes`**
