# 🛡️ | Letztes Wort schützen

### 📦 Zugehöriges System

**Word Chain**

### 🖱️ Kontextmenü-Aktion

**`Protect Last Word`**

### Beschreibung

Mit dieser Nachrichten-Aktion kann das letzte Wort einer Nachricht im Word-Chain-System geschützt werden.

Die Aktion wird direkt auf einer entsprechenden Nachricht ausgeführt und ermöglicht es berechtigten Teammitgliedern, das letzte Wort dieser Nachricht vor Veränderungen durch die reguläre Word-Chain-Logik zu schützen.

### Verwendung

Öffne das Kontextmenü der entsprechenden Nachricht und wähle:

**Apps → `Protect Last Word`**
